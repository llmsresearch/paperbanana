# Example posters

Conference posters generated by `paperbanana poster` directly from each paper's
PDF — designed by an image model, grounded and faithfulness-audited against the
paper, with the paper's **real figures embedded**, rendered at the venue's exact
physical size. Each folder has a downscaled `preview.png` and a `poster.pdf`
(compressed for the repo; the command produces a full-resolution print PDF).

Papers are a spread from Sebastian Raschka's
[LLM Research Papers 2026 (Part 1)](https://magazine.sebastianraschka.com/p/llm-research-papers-2026-part1).

| Example | Paper | arXiv | Venue (size) |
|---|---|---|---|
| `mimo_v2_flash/` | MiMo-V2-Flash Technical Report | [2601.02780](https://arxiv.org/abs/2601.02780) | NeurIPS (1219×914 mm) |
| `vit5/` | ViT-5: Vision Transformers for the Mid-2020s | [2602.08071](https://arxiv.org/abs/2602.08071) | CVPR (2134×1067 mm) |
| `massive_activations/` | The Spike, the Sparse and the Sink | [2603.05498](https://arxiv.org/abs/2603.05498) | ICLR (1189×841 mm) |
| `mamba3/` | Mamba-3: Improved Sequence Modeling | [2603.15569](https://arxiv.org/abs/2603.15569) | ICML (1219×914 mm) |
| `gated_deltanet2/` | Gated DeltaNet-2 | [2605.22791](https://arxiv.org/abs/2605.22791) | NeurIPS (1219×914 mm) |

```bash
paperbanana poster --paper 2602.08071.pdf --venue cvpr \
  --figures auto --qr-url https://arxiv.org/abs/2602.08071
```

## Honest notes

- **Faithfulness:** a VLM re-reads each rendered poster against the paper and
  flags contradictions (the audit drives repair). It surfaces *candidate*
  discrepancies and can over-report; per-finding verification is a planned
  precision upgrade.
- **Figures:** with `--figures auto` the paper's real figures are embedded —
  re-rendered crisp from the PDF, or reauthored behind a faithfulness gate when
  a source is too low-resolution for poster scale.
- **Print resolution:** the committed PDFs are compressed for the repo; run the
  command yourself for the full-resolution, print-ready file at the venue size.
