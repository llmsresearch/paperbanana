TITLE: Semantic Understanding of Scenes through the ADE20K Dataset  
AUTHORS: Bolei Zhou, Hang Zhao, Xavier Puig, Tete Xiao, Sanja Fidler, Adela Barriuso, Antonio Torralba  
VENUE: unknown  
ONE-LINE TAKEAWAY: The ADE20K dataset contains 25k images with dense pixel-wise annotations across 3,169 classes (2,693 object/stuff and 476 parts), enabling state-of-the-art scene parsing and instance segmentation benchmarks.  
PROBLEM:  
- Current datasets lack comprehensive coverage of diverse scenes and object categories with pixel-level annotations.  
- Existing datasets often have limited object classes or noisy labels, hindering fine-grained semantic understanding.  
METHOD:  
- Collect and annotate 25,000 images from LabelMe, SUN, and Places datasets.  
- Use a single expert annotator to label objects, stuff, and object parts with hierarchical relationships.  
- Construct two benchmarks: scene parsing and instance segmentation.  
- Re-implement state-of-the-art models for open-source evaluation.  
- Evaluate synchronized batch normalization effects on segmentation performance.  
RESULTS:  
- 25,000 total images (20,210 training, 2,000 validation, 3,000 testing).  
- 3,169 class labels annotated (2,693 object/stuff, 476 parts).  
- Average of 19.5 instances and 10.5 object classes per image.  
- Average of 29 annotation segments per image (vs. 16 by external annotators).  
- Validation set fully annotated with parts; training set not exhaustively annotated.  
KEY NUMBERS:  
- 25,000: Total number of images in the ADE20K dataset.  
- 3,169: Total number of annotated classes (object/stuff + parts).  
- 19.5: Average number of instances per image.  
- 10.5: Average number of object classes per image.
